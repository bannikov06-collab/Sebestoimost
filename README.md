# KLM — себестоимость шинопровода

Резервный комплект KLM v32, подготовленный 08.09.2026 из полного экспорта от 24.08.2026 и накопительных патчей по CHANGE 05U включительно.

## Состав репозитория

- `source/` — восстановленный исходный код сайта с последовательно наложенными патчами CHANGE 05J–05U;
- `database/` — контрольный экспорт D1 от 24.08.2026: SQL, JSON и сводка проверки;
- `uploads/` — файлы, входившие в контрольный полный экспорт проекта;
- `reference/` — КД 4P/5P/IP68, каталог, структура обозначений, сводная таблица материалов и актуальные цены;
- `patches/` — накопительные и исторические пакеты обновлений;
- `docs/` — инструкция пользователя, презентация и видеоинструкция;
- `tools/` — служебные сценарии восстановления и проверки.

## Актуальное состояние

- production: `https://klm-v32.bannikov-06.workers.dev`;
- последний подтверждённый патч: `CHANGE 05U`;
- Cloudflare bindings: D1 `DB`, R2 `BUCKET`;
- секреты и локальные файлы авторизации в репозиторий не включаются.

Снимок `database/` не является актуальным экспортом рабочей D1 на 08.09.2026. Исходник также не содержит локальный `wrangler.jsonc` с рабочего компьютера. Для точной копии production необходимо добавить актуальную папку `C:\Users\Adm-KLM\KLM-v32-recovery\source`, экспорт действующей D1 и новые объекты R2 из Cloudflare.

Подробности перечислены в `DATA_STATUS.md`.

## Проверка исходного кода

```bash
cd source
npm ci
npm test
```

## Развёртывание

Рабочие идентификаторы D1/R2 и секреты задаются в окружении Cloudflare и не должны сохраняться в Git. Публикация выполняется из каталога `source` после успешной сборки и тестов.
