# Восстановление KLM в личном аккаунте ChatGPT

1. Создайте новый проект ChatGPT `KLM — калькулятор себестоимости`.
2. Добавьте ZIP-архив и `KLM_PROJECT_HANDOFF_2026-08-24.md` в источники проекта.
3. Запустите ChatGPT Work и попросите сначала только проверить архив, не публикуя Site.
4. Создайте новый ChatGPT Site из каталога `source/`. Не подключайте его к старому проекту.
5. При создании Site платформа должна добавить новый `project_id` в `source/.openai/hosting.json`. Старого идентификатора в архиве нет.
6. Создайте D1 с логической привязкой `DB` и R2 с привязкой `BUCKET`.
7. Примените миграции из `source/drizzle/`.
8. Импортируйте `database/backup.sql`.
9. Проверьте: `calculations` — 5, `assignment_history` — 0, `workspace_records` — 40.
10. Загрузите 11 файлов из `uploads/` в новый R2 по `database/r2-files-manifest.json`.
11. Обновите в восстановленных записях `payload_json.storageKey` на фактические ключи нового R2.
12. Выполните `npm ci`, затем `npm test`; ожидается 43 из 43 тестов.
13. Проверьте заказы IP55, заказ IP68, документы, складские остатки и сохранённые расчёты.
14. Сначала сохраните версию без публикации. Публикуйте только после отдельного подтверждения владельца.

## Стартовая команда для нового чата

```text
Ты принимаешь полный архив проекта KLM. Сначала прочитай README_FIRST.md,
KLM_PROJECT_HANDOFF_2026-08-24.md и RESTORE_IN_PERSONAL_CHATGPT.md.

Ничего не изменяй и не публикуй до завершения проверки. Создай новый Site,
новые D1 DB и R2 BUCKET; не подключайся к старому проекту. Восстанови D1 из
database/backup.sql и 11 файлов R2 по database/r2-files-manifest.json.

Агенты работают только на чтение. IP55 считать только при явном указании.
IP68, неизвестный IP и конфликт IP55/IP68 блокировать. Не выполнять
автоматические исправления. После восстановления покажи контрольные количества,
результаты 43 тестов и перечень расхождений. Не публикуй без моего разрешения.
```

## Секреты

Секреты не восстанавливаются из архива. Если новому Site потребуются внешние ключи, добавьте их вручную в настройках Site как новые значения. Не вставляйте секреты в чат, файлы или `.openai/hosting.json`.
