# CHANGE 05U — 5P и стандартный ряд CML

## Принятые правила

- 5P: четыре рабочих проводника и отдельная PE-шина в каждом пакете.
- Число физических шин: `проводность × число пакетов`.
- ПЭТ и электротехническая лента: только A/B/C/N, то есть `4 × число пакетов`.
- ПОС: на все физические шины, включая PE каждого пакета.
- CD 2000 А: шина 6×200 по `131.20.CD.001.000СБ` и деталировкам `.001–.009`.
- Стык G остаётся отдельным элементом с L1=L2=L3=0.
- Болт стыка: M12×130 для 4P по `012.001`, M12×140 для 5P по `012.003`.

## CML

- Поддержаны 4P и 5P для 630, 800, 1000, 1250, 1600, 2000, 2500,
  3200, 4000, 5000 и 6300 А.
- Стандартный габарит из каталога: 1500 мм.
- Центральный конструктив: 242 мм; две прямые FE: по 629 мм.
- Для исполнения 1300 мм по `131.06.CML.011.000.000СБ`: две FE по 529 мм.
- Число КША: `проводность × число пакетов`; PE присутствует в каждом пакете.
- Вариант 630 А 5P использует подтверждённые КД параметры:
  5 КША, 21 пластина АД1М 0,3×100 на КША и два наконечника по 35 мм.
- Варианты без отдельной деталировки формируются масштабированием стандартного
  конструктива и маркируются в обосновании ресурса как расчётные.

## Контроль

Автотесты проверяют полный ряд CML, обе проводности, повторение PE по пакетам,
отсутствие ПЭТ на PE, конфигурацию CD 2000 А и крепёж стыков 4P/5P.
