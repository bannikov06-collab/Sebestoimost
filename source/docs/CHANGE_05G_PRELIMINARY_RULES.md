# KLM v32 CHANGE 05G — предварительная спецификация без L1/L2/L3

Дата правила: 2026-08-30.

## Основание

- Заполненный пользователем файл `Правила_предварительной_спецификации_2026-08-30.xlsx`.
- `2025.10.20_Эскизы_секций_V7.pdf` — геометрическое значение L1/L2/L3 по типам секций.
- Утверждённая таблица стандартных размеров KLM-S, уже установленная в CHANGE 05A и используемая последующими версиями.

## Утверждённое правило предварительного расчёта

1. Предварительная спецификация может не содержать L1/L2/L3.
2. Если позиция `Стандарт` или класс S1 — используются стандартные размеры семейства по номиналу и 4P/5P.
3. S2 = 1500 мм, S3 = 2500 мм по умолчанию.
4. Для семейства с одним расчётным размером S2/S3 изменяют только L1.
5. Для семейства с двумя или тремя расчётными размерами S2/S3 изменяют только L2. L1 и L3 остаются стандартными.
6. Считать только конструктивно существующие размеры: FE — L1; CD/CP/ATSC — L1/L2; ZD/ZP/ZDP/TP/TD/ATCP/ATCD — L1/L2/L3.
7. Если в производственной спецификации размеры явно заданы, они имеют приоритет; CHANGE 05G меняет только предварительный расчёт.
8. Для FE и Pi без EC стандартная предварительная длина — 3000 мм.
9. Нестандартная строка без явного S-класса в предварительном расчёте использует S1 как безопасный стандартный baseline и не требует ручного L1/L2/L3.
10. ATT и CML остаются специализированными моделями CHANGE 05F; комбинированные ATT/CML не подменяются generic-семействами.

## Сопоставления для предварительного расчёта

Дополнительно разрешены безопасные алиасы базовых семейств:
- CD-SA / CDSA -> CD
- CP-SA / CPSA -> CP
- ZD-SA / ZDSA -> ZD
- ZP-SA / ZPSA -> ZP
- ZDP-SA / ZDPSA -> ZDP
- FE-SZ, FE4 -> FE
- Pi, Pi-1, Pi-2, Pi-3, Pi-4, Pi-6, Pi-8, Pi-10, Pi-12 и другие Pi без EC -> FE

Варианты с EC и комбинированные составные типы не раскрываются автоматически, если для них нет отдельного подтверждённого BOM/правила.

## UI

В панели предварительной спецификации:
- S1 показывается как `стандартные размеры`;
- S2/S3 показывают целевой размер;
- текст больше не утверждает устаревшее `S1=750 мм`;
- статус рассчитанной строки показывает, какой размер изменён правилом.
