# CHANGE 05L — калькулятор и ресурсная спецификация

- В калькулятор возвращены сценарии исходного номинала, на один и на два номинала ниже.
- Ток, стандартные размеры и материалы пересчитываются для всех строк проекта; пример 2000 → 1600 → 1250 А.
- Добавлена выгрузка сводной ресурсной спецификации проекта в XLSX.
- В выгрузке для профиля, шин, крышек и боковин сохраняются метры, масса и потребность в трёхметровых заготовках.
- Стык G отображается отдельной карточкой элемента: тип, ток, проводность, артикул, количество и нулевые L1/L2/L3.
- Ресурсная спецификация каждого стыка раскрывается кнопкой внутри его карточки.
- Порядок калькулятора: результат переноса → контрольный контур → перечень элементов → сводный ресурсный состав.
- Стык G остаётся исключённым из FE/CD/CP/ZD/ZDP и других секций.
