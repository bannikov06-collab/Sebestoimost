# KLM v32 — CHANGE 05F — ATT / CML

Дата фиксации: 2026-08-29.

## CML 3200 4P
- Основная КД: `132.32.CML.001.000`.
- Две стандартные FE 3200, каждая L=629 мм.
- Стандартный общий габарит CML 3200: 1500 мм.
- Базовая гибкая часть: 150 мм.
- Изменение общего габарита CML переносится 1:1 только на гибкую часть; FE не масштабируются.
- G не входит автоматически в состав CML; учитывается только отдельной строкой спецификации.
- На проводник 3200 А: 2 КША. Для 4P: 8 КША по материалу, объединяемых в 4 монтажных узла.
- Один КША: 26 гибких пластин АД1М 0,3×160; фактический пакет 7,8 мм, запас 11,43% к базовым 7 мм.
- Контактные наконечники: АД0 6×160; 100 мм и 120 мм.
- GM-3828 25 мм, код 1С `Ц0000077668`: верхний + нижний торец по всей длине гибкой части.
- Термоусадка: обязательна; 1 отрезок на каждый КША; L = Lгибк + 30 мм; подбор по диапазону. Для 160 мм — ТТШт 180/58 35 кВ.
- PE-пластина: АМг3 2,0, код исходного материала `Ц0000069668`, 2×0,5 кг.
- Крышка `132.12.CML.001.200`: 2 комплекта; деталь `201` 1,11 кг + гаскетинг 0,04 кг.

## ATT 4P
Расчёт разрешён только для подтверждённых КД: 1000, 3200 и 5000 А. Другие номиналы/5P не получают автоматически эту модель.

Общие утверждённые правила:
- Выходных токоведущих шин всегда 4, независимо от числа внутренних пакетов.
- Материал выходных шин: АД0.
- Поликарбонат: код `Ц0000066254`, толщина 10 мм, 4 изолятора по числу выходных шин; отверстия не вычитаются.
- Для ATT >2 пакетов: контрольный габарит листовой конструкции H = Hнаружный - 39 мм; при расчёте электрического сечения принимаются толщина и ширина основной шины.
- Времена производственных операций не назначаются без подтверждённых норм.

### ATT 1000
Основная КД `132.10.ATT.013.000.000`; 4 выходные шинные сборки. Для материала выходных шин используется АД0 6×100. Точная контрольная масса токоведущих сборок по дочерним КД: 6,9 кг.

### ATT 3200
Основная КД `132.32.ATT.011.000.000`; 2 внутренних пакета, но 4 выходных проводника. Восемь деталей шин КД объединяются попарно в 4 выходных проводниковых сборки; суммарная контрольная масса 40,30 кг. Изоляторов для расчёта — 4, а не буквальные 8 сборочных позиций КД.

### ATT 5000
Основная КД `132.50.ATT.011.000.000`; 4 внутренних пакета и 4 выходных проводника. Материал токоведущих шин переопределён пользователем с A5M на АД0. Контрольная масса четырёх шинных сборок по основной КД — 81,9 кг. Стандартный Hнаружный=721 мм → контрольный Hлист=682 мм; контрольный размер поликарбоната по правилу +80 = 762 мм.

## Неподтверждённые данные, которые не подменяются нулевым «готовым» правилом
