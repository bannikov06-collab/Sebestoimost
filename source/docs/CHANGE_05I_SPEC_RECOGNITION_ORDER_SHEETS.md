# KLM v32 — CHANGE 05I

Дата: 2026-08-30

## Что исправлено

1. Предварительная спецификация распознаётся прежде всего по артикулу, а не по совпадению текста наименования со справочником.
2. S1/S2/S3 трактуются только как классы предварительной длины. S1 больше не может быть ошибочно подменён каталогом CP-SA/CD-SA из-за одинакового наименования.
3. CP-SA рассчитывается семейством CP, CD-SA — семейством CD; отличающийся угол не меняет материальную/стоимостную модель.
4. Прямое распознавание из артикула добавлено для FE/Pi, CD, CP, ZD, ZP, ZDP, TP, TD, ATT, CML, ATSC, ATCP, ATCD.
5. В калькуляторе себестоимости строки больше не переставляются: порядок соответствует загруженной спецификации. Отдельная сортировка по дефициту/складу остаётся только в «Потребность и склад» / снабжении.
6. При переносе спецификации одинаковые строки не объединяются до калькулятора: каждая строка сохраняет своё место. Материалы агрегируются позже в контуре потребности.
7. Листовой материал в потребности пересчитывается из кг в целые листы по габариту листа. Для алюминиевых листов используется действующая плотность 2710 кг/м³; для стальных/оцинкованных — 7850 кг/м³. Округление — вверх до целого листа.
8. В XLSX заказа материалов колонка «Листы, шт.» заполняется рассчитанным количеством целых листов.

## Что не менялось

- Формулы S1/S2/S3 из CHANGE 05G.
- Стоимость с 2 знаками после запятой из CHANGE 05H.
- Специализированные ATT/CML модели CHANGE 05F.
- Отдельный блок G и правило «G только отдельной строкой спецификации».
- Сортировка планирования потребности по обеспеченности/дефициту.
- D1/R2 и схема БД.

## Ограничения

Распознавание артикула не создаёт отсутствующую КД. Если для конкретного номинала ATT/CML/ATSC нет разрешённой расчётной модели, строка должна остаться с явной причиной, а не получать выдуманную стоимость.
