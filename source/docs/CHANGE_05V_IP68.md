# CHANGE 05V — расчёт KLM-S IP68

## Введённые правила

- IP68 определяется только по явному признаку исполнения; конфликт IP55/IP68 блокирует расчёт.
- Поддержан диапазон 160–5000 А. Номинал 6300 А остаётся заблокированным до утверждения конструктива.
- В 4P каждый пакет содержит четыре рабочих проводника.
- В 5P каждый пакет содержит четыре рабочих проводника и отдельную PE-шину.
- Для IP68 ПЭТ и лента учитываются на рабочих шинах и PE.
- Высота боковины IP68 равна высоте шины плюс 33 мм. Пока подтверждённый профиль IP68 отсутствует, боковина рассчитывается из листа.
- Компаунд: VeraBond IZC-10, код 1С Ц0000066360, плотность 1,44 кг/л, A:B = 100:30, цена системы 416 руб./кг, технологические потери 0%, производительность оборудования 95 г/с.
- Стык IP68 5P рассчитывается отдельно по 012.007.000; L1/L2/L3 равны нулю; применяется 6 изоляторов. Компаунд стыка не включён до получения подтверждённого расхода.
- Синтокартон исключён из себестоимости, потребности и складского планирования.
