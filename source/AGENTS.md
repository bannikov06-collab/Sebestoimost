# Правила разработки KLM

- Основной и единственный развиваемый проект: TypeScript/React в этом репозитории ChatGPT Sites.
- Python-версия является архивной историей. Не переносить в неё новые функции и не использовать её для публикации.
- Все изменения выполнять только в текущем checkout ChatGPT Sites, сохраняя существующую архитектуру и `.openai/hosting.json`.
- После каждого завершённого изменения обязательно:
  1. проверить изменённый пользовательский сценарий;
  2. выполнить тесты и производственную сборку;
  3. создать отдельный понятный Git-коммит;
  4. опубликовать новую версию через ChatGPT Sites;
  5. проверить успешность развёртывания и сообщить пользователю актуальную ссылку.
- Не изменять архивные Python- и прежние локальные TypeScript-копии вне этого checkout.
- Не выдумывать формулы себестоимости, нормы расхода, коды 1С и правила сопоставления материалов. Неподтверждённые позиции показывать отдельно.
- Агенты контроля работают только на чтение и не исправляют документы, расчёты, справочники, заказы или базу автоматически.
- IP55 рассчитывать только при явном признаке исполнения. IP68, неизвестное IP и конфликт IP55/IP68 блокировать до получения подтверждённых исходных данных.
- Полностью заблокированный заказ не должен очищать уже открытый расчёт.
- После переноса не подключаться к старому Sites-проекту: создать новый `project_id`, новую D1 `DB` и новый R2 `BUCKET`.
