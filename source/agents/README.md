# Агенты контроля KLM

Все четыре агента работают детерминированно и только в режиме чтения. Они формируют замечания, но не изменяют документы, спецификации, расчёты, справочники, заказы или базу данных.

1. `01-specification-agent.md` — разбор исходной спецификации и признаков изделия.
2. `02-materials-agent.md` — проверка количества и состава материалов.
3. `03-drawings-agent.md` — контроль КД, номера чертежа и версии.
4. `04-project-audit-agent.md` — объединение результатов в статус `passed`, `review` или `blocked`.

Программная реализация находится в `app/lib/projectAgents.ts`. Любое исправление по замечанию агента выполняется только после отдельного решения пользователя.
