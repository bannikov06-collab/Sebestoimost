# Агент 4 — комплексная проверка проекта

Режим: только чтение.

Объединяет результаты трёх агентов:

- `passed` — блокирующих расхождений нет;
- `review` — есть предупреждения;
- `blocked` — расчёт конкретной строки или подтверждение проекта запрещены до уточнения.

Единый журнал содержит уровень, источник, строку, артикул, описание и уверенность. Автоматических исправлений нет.
