# Полный архив проекта KLM

Дата пересборки: 24.08.2026.

Архив предназначен для переноса калькулятора себестоимости шинопровода KLM в новый личный аккаунт ChatGPT без подключения к исходному рабочему Site.

## Состав

- `source/` — полный исходный код TypeScript/React, миграции D1, тесты, правила и четыре агента контроля;
- `database/backup.sql` — восстановление D1;
- `database/*.json` — таблицы D1 в машиночитаемом виде;
- `database/backup-summary.json` — контрольные количества;
- `database/r2-files-manifest.json` — соответствие записей базы и файлов;
- `uploads/` — 11 выгруженных документов R2;
- `KLM_PROJECT_HANDOFF_2026-08-24.md` — полное описание проекта;
- `RESTORE_IN_PERSONAL_CHATGPT.md` — инструкция переноса;
- `EXPORT_VALIDATION.json` — результаты проверки архива.

## Обязательные ограничения

- исходный `project_id` удалён; новый аккаунт должен создать собственный Site;
- логические привязки сохраняются как D1 `DB` и R2 `BUCKET`;
- секреты, токены и пароли в архив не включены;
- IP55 рассчитывается только при явном признаке исполнения;
- IP68, неизвестное IP и конфликт IP55/IP68 заблокированы;
- четыре агента работают только в режиме чтения;
- автоматические исправления документов, расчётов и базы запрещены.

Начните с файлов `KLM_PROJECT_HANDOFF_2026-08-24.md` и `RESTORE_IN_PERSONAL_CHATGPT.md`.
